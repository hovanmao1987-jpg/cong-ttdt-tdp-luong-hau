# DỰ ÁN CỔNG THÔNG TIN ĐIỆN TỬ TỔ DÂN PHỐ LƯƠNG HẬU (TP. HUẾ)
Dự án chuẩn hóa dành cho Google Antigravity, Vercel & Astro.

## 1. Khu Vực Công Khai (Chuẩn Hue.gov.vn Mobile V3)
- File tĩnh: `index.html`
- File Astro: `src/pages/index.astro`
- Tính năng: Tin tức 3 cấp (TP Huế, Hương Thủy, Lương Hậu), Chuyên mục ANTT & PCTT (Nhật ký tuần tra đêm, phương án trực bão lũ 10-17/9), Công khai 10 cán bộ chủ chốt, Kho 11 biểu mẫu tải miễn phí, Form tiếp nhận phản ánh công dân, Chuyên mục chính & Liên kết Quốc gia.

## 2. Khu Vực Nội Bộ Chi Bộ (Chuẩn DangCongSan Mobile V2)
- File tĩnh: `noi_bo.html` (truy cập: `/noi-bo` hoặc `#/noi-bo/dashboard`)
- File Astro: `src/pages/noi-bo.astro`
- Tính năng: 
  - Lớp bảo mật đối soát CCCD & Họ tên Đảng viên được Bí thư Chi bộ phê duyệt.
  - Sổ tay Đảng viên điện tử Thừa Thiên Huế (sotaydangvien.hue.gov.vn).
  - Mục các Văn bản của Chi bộ TDP Lương Hậu (Nghị quyết 09, Tờ trình 11, Biên bản 08, Giám sát & Kiểm tra Điều 30, Thông báo 14 & 15).
  - Mục Quản lý cán bộ, đảng viên thu gọn với nút bấm mở Dashboard phân công nhiệm vụ "6 Rõ" (10 cán bộ, tiến độ bình quân 87.0% Xuất sắc).
  - 4 Nút Tư liệu Văn kiện Đảng: Điều lệ Đảng, Văn kiện Đảng toàn tập, Hội nghị Trung ương, Văn bản của Đảng.
  - Hệ thống văn bản mới Trung ương (556-QĐ/VPTW, 213-KH/VPTW, 91-KL/TW, 27-NQ/TW).

## 3. Cách chạy trên Google Antigravity:
1. Mở Antigravity IDE -> Chọn Open Folder trỏ vào thư mục này.
2. Nhắn lệnh: "Khởi chạy local server và mở trình duyệt chế độ Mobile để kiểm tra index.html và noi_bo.html".
